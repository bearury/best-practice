🚀 Git Release Cheatsheet

Стратегия: feature-ветки → develop (тест) → release (выборочный cherry-pick)

нажми на блок кода чтобы скопировать

1 Новая задача безопасно

создать ветку от develop

git checkout develop
git pull
git checkout -b feature/TASK-123-описание

работать, коммитить свободно

git add . && git commit -m "wip"
git add . && git commit -m "fix"
git add . && git commit -m "done"
Коммитов может быть сколько угодно — на этом этапе порядок не важен.

2 Squash перед мержем важно

склеить все коммиты задачи в один

# Интерактивный rebase на develop
git rebase -i develop

# В редакторе: первый оставить pick,
# остальные заменить на squash (или s)
# Написать итоговое сообщение:
# "TASK-123: Описание что сделано"

или проще — soft reset

# Узнать сколько коммитов
git log --oneline develop..HEAD

# Склеить N коммитов в один
git reset --soft develop
git commit -m "TASK-123: Описание"
Зачем? Один коммит = одна задача. Тогда cherry-pick берёт всю задачу целиком без проблем.

3 Мерж в develop безопасно

влить задачу в общую сборку

git checkout develop
git pull
git checkout feature/TASK-123-описание
git merge develop
# Решение конфликтов, при необходимости
git push
Теперь задача в develop — QA тестирует полную сборку со всеми задачами вместе.

4 Посмотреть все задачи безопасно

что есть в develop, чего нет в main

git log --oneline main..develop

вывод

2c9eeb6b TASK-45: Исправлена галерея в Safari
a1b2c3d4 TASK-38: Редизайн техмерча
e5f6g7h8 TASK-52: Новые отчёты
i9j0k1l2 TASK-41: Фикс клика по меню
Каждая строка = одна задача (благодаря squash). Берёшь хеш нужных.

5 Собрать релиз внимательно

создать ветку релиза от последнего прода

# Если main не чистый — от последнего тега
git checkout -b release/2.5.0 v2.4.0

# Или от main если он чистый
git checkout main
git checkout -b release/2.5.0

cherry-pick только нужные задачи

# Берём задачи 45 и 41, НЕ берём 38 и 52
git cherry-pick 2c9eeb6b  # TASK-45
git cherry-pick i9j0k1l2  # TASK-41

# Тестируем → если ОК → пуш
git push -u origin release/2.5.0

или если все задачи:

git cherry-pick main..develop

6 Версионирование на подумать !!!!

⚡ Конфликты при cherry-pick

Ситуация Команда
Отменить cherry-pick git cherry-pick --abort
Решить и продолжить git add . && git cherry-pick --continue
Пропустить коммит git cherry-pick --skip
Посмотреть конфликты git diff --name-only --diff-filter=U
Конфликты чаще если задачи меняют одни файлы. Squash уменьшает шанс конфликтов.

🔧 Полезные команды

Что Команда
Разница develop vs main git log --oneline main..develop
Файлы в коммите git diff-tree --no-commit-id --name-only -r HASH
Сравнить 2 ветки git diff branch1..branch2 --stat
Все ветки с upstream git branch -vv
Список тегов git tag -l --sort=-v:refname
Сохранить коммит на ветку git branch backup/name HASH
Применить коммит git cherry-pick HASH
Отменить последний коммит git reset --soft HEAD~1
